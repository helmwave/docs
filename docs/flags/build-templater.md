### `--build-templater`

> Introduced in [:material-tag: v0.43.0](https://github.com/helmwave/helmwave/releases/tag/v0.43.0)


You can define template engine only for rendering `values` files during build.
It overrides [`--templater`](#-templater) for that step.

Please visit [templating reference](../tpl) for more details.
